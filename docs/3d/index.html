Model scope

Generated from the public six-layer review PCB with the routed copper, board, solder mask, pads, silkscreen, and 3D package bodies. Models were added only to a scratch copy; the published KiCad board was not edited.

Generic KiCad library bodies show package form, not the exact manufacturer part number or its tolerances.

Stand-ins and omissions

  • X6 USB-C uses a GCT USB4105 library model, positioned by matching its main pad row to the local footprint. It is not the fitted HRO connector.
  • L1 uses a same-size inductor package stand-in, not the TDK VLS5045EX model.
  • J1's JST ACHL speaker connector and both rear battery contacts are omitted; their exact bodies and mating wire remain important mechanical work.
  • Q3 and Q5 are also omitted because no sufficiently matched library bodies were available.
  • Test lands, mounting holes, and solder jumpers are shown as board features, not fitted parts. DNP C29 is excluded.

Rebuild and attribution

KiCad 10.0.6 rendered the model using its 3D model library; the optimization step uses glTF Transform. See the source and asset manifest, build and provenance notes, and project attribution.
