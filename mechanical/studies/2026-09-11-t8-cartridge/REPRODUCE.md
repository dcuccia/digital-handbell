# Reproduce only the new T8 study

From `C:\Projects\dcuccia\digital-handbell`:

```powershell
$FreeCAD = "$env:LOCALAPPDATA\Programs\FreeCAD 1.1\bin\FreeCADCmd.exe"
python .\tools\build_t8_cartridge.py --freecad-cmd $FreeCAD --placement .\hardware\handbell\iterations\t8-protected-draft\placement-manifest.json
python .\tools\check_t8_cartridge.py
```

The installed target is FreeCAD1.1.3; the generated report records actual
FreeCAD/OpenCASCADE/bundled-Python versions. Ordinary launcher Python does not
need the FreeCAD modules. No pip, add-on, GUI or existing-generator invocation
is needed.

To change a declared mechanical parameter:

```powershell
python .\tools\build_t8_cartridge.py --freecad-cmd $FreeCAD --placement .\hardware\handbell\iterations\t8-protected-draft\placement-manifest.json --parameters .\mechanical\studies\2026-09-11-t8-cartridge\parameters.json
```

This does not edit a PCB, manifest, shared measurement record or historical
study. The output may be redirected only to a child directory of this study.
The exact input hashes are checked before/after generation. Missing final
electrical input is an error; there is no automatic wing-manifest fallback.

The current coordinated source already contains PCB Fz14.25/Bz15.85, the
z25.63 cell axis and outward USB mouthy-27.90. The builder uses those **actual
source coordinates**, derives the matching speaker/front-body shift, and keeps
the measured mouth register fixed. Do not feed the old fixed-stack manifest
and relabel its model as the new placement.

Parameters ending `_from_speaker_mm` are relative to the speaker front.
`cover_split_above_board_back_mm` is relative to the source PCB B plane.
Effective absolute datums are in `fit-report.json` under `stack_interface`;
the contact interface takes precedence over fallback cell dimensions.
The chosen plastic target is1.0 mm with0.10 mm nominal clearances.

The current build also consumes the dated owner spacing-feedback record and
embeds its exact bytes. It evaluates the requested 0.5/1.0 mm PCB-only spacing
reductions in the report without altering the delivered mechanical/electrical
interface. This avoids a second independent model that could silently diverge
from the placed board.

To reproduce the bounded comparison independently of the now-shifted output:

```powershell
python .\tools\screen_t8_stack_shift.py
```

It reads only the frozen `alternatives\baseline-fixed-stack` source/native
snapshots and writes `alternatives\whole-stack-screen`. It tries1.5/2 mm,
then two quarter-millimetre brackets calculated from the upper-contact corner,
for1.0 and1.25 mm plastic. It does not edit electrical data or run an optimizer.
The old baseline's copied README/tool sources are historical records in their
original context, not current build instructions.

Isolated FreeCAD preferences and the run marker live in a uniquely named
directory **inside this study**, are removed afterwards, and never use the
operating system temporary directory. The console runs synchronously with a
30-minute limit. `freecad-build.log` is local diagnostic output. Because
FreeCAD's console can return zero after a Python exception, a fresh token and
matching source hashes—not return code alone—are required for success.

`review-status.json` is marked build-in-progress before launch. A previous
STEP/native file existing after failure is not evidence of a completed run.
`completion.json` identifies the last completed run and its artifact manifest.

The script imports only pure geometry/export helpers from unchanged
`tools\build_mechanical.py`. It never invokes that older generator or reads
its old shell/placement parameters. Its raw bytes/hash are embedded alongside
the new builder, exact new electrical manifest and exact measurement record.
No old output path is written.

Native color/transparency/visibility properties are saved in `GuiDocument.xml`
without creating a GUI session. They are inspectable XML, not a claimed GUI
rendering test. The parent workflow coordinates the owner's actual FreeCAD
review before routing.

The ordinary-Python checker validates output hashes, exact consumed input
bytes, current upstream binding, required native members/source records and
reported BRep/mesh round-trips. It also requires no unintended nominal material
overlaps, the chosen0.25 mm guard-stock/shell margin and sufficient actual
material at the declared under-cell section. It reports qualification gates
separately from artifact integrity. Geometry Booleans and distances require FreeCAD and are
regenerated by the build; the checker does not pretend to independently solve
CAD using bounding boxes.
